还差一步：创建 Supabase 项目
  1. 去 supabase.com 注册，新建一个免费项目。
  2. 打开左侧 SQL Editor，把 supabase-setup.sql 整段粘贴执行。
  3. 在 Project Settings → API 复制 Project URL 和 anon public key，填进 supabase-config.js，重新部署。
  4. 注册你自己的账号后，再执行 SQL 文件最后那句 update，把自己设成管理员。
