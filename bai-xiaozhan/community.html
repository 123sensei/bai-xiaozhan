    讨论大厅

    Giscus · GitHub

    讨论由 GitHub Discussions 承载，作者不用自己维护服务器，也自带账号、删除和屏蔽。第一次发言，要用 GitHub 账号授权一次。

    还差一步：把讨论区接到你的 GitHub 仓库
    1. 建一个公开的 GitHub 仓库，在 Settings 里打开 Discussions。
    2. 打开 giscus.app，按提示安装 Giscus App，选好仓库和分类，页面会生成一段配置。
    3. 把配置里的 repo、repoId、category、categoryId 填进 community.js 顶部，重新上传一次就能用。

    没配置之前，这里不会显示评论框，避免出现一块打不开的空白。

    讨论区遵守下面的社区规则。看到违规内容，点最下面的「举报一条内容」，把链接发到作者邮箱。

    社区规则

    先看再发言
    1. 不骂人、不人身攻击。对内容可以较真，对人不行。
    2. 不发广告。拉群、加微信、刷单、代开发票一律删除。
    3. 不发违法和侵权内容。包括盗版资源、别人的隐私、身份证照片。
    4. 不刷屏。同一句话连发、无意义灌水，会影响别人阅读。
    5. 提问前先搜一下。很多问题在第 11 节和常见问题里已经有答案。

    违规怎么处理

    1

    提醒：第一次轻度违规，删内容并提醒。

    2

    禁言：反复违规，暂停发言。

    3

    封号：严重违规或屡教不改，直接封禁。

    封号只能由作者本人解封。觉得处理错了，用反馈表单选「其他」，写清昵称和情况，作者人工复核。

    说明：这套站是纯静态的，违规词检查只在你的浏览器里提示，挡不住刻意绕过的人；真正的删除和封号，目前靠 GitHub 讨论区权限和作者人工处理。要做成自动拦截和封号，必须有后端。
